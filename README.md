# Customer Retention & Churn Analysis

## Project Overview
This project analyzes customer churn behavior to identify retention risks and customer exit patterns.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Key Insights
- Around 26.5% of customers churned.
- Month-to-month contracts showed highest churn.
- Electronic check users churned the most.
- Long-term contracts improved retention.

## Recommendations
- Encourage long-term subscriptions.
- Improve retention for month-to-month customers.
- Investigate payment-related churn issues.
